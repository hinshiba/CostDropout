# 計画

## モデル

帳簿: 1つのgitリポジトリ
- 情報
  - 品目
  - 取引
  - 予算
  - commit履歴
- 操作
  - 変更の保存(commit)と共有(push)
    - 複数人編集時の競合検出は `git push` のfast-forward判定を用いる
  - commitの追跡による監査

品目
- 情報
  - 名前(任意の文字列)
  - 分類タグ(資産/負債/初期残高(純資産)/収入(収益)/支出(費用))
  - 階層構造をタグに対してのみ間接的に持つ
  - 品目に階層は設けない
  - プリセットをもつ
    - 食費(支出)
    - 娯楽(支出)
    - 日用雑貨(支出)
    - 衣服/美容(支出)
    - 定期支出(支出)
    - その他(支出)
- 操作
  - 利用者が任意の文字列で追加できる
  - 編集，削除できる(プリセットも削除できる)
    - 取引が属している品目は削除できない

取引
- 情報
  - 日付
  - 金額
  - 品目に属する
    - 相手先は自身分類タグ以外の任意
  - コメント
- 操作
  - 追加
  - 訂正
  - 削除
  - 品目は収入/支出/負債のみ選択できるようにする

予算
- 情報
  - 予算額(お金)
  - 期間(月単位を基本とする)
- 操作
  - 予算と期間を設定できるようにする
  - 期間内の支出合計と比較する

お金
- 情報
  - i32
- 操作
  - 加算
  - 減算
  - 合計

## ビュー

- 1か月の支出の品目割合を示す円グラフ
- 1か月ごとに，合計支出と収入金額を表示
  - 1日から31日までの日ごとの内訳も分かるようにする
- 選択した品目のみの支出を示す棒グラフ
- 年，月ごとの合計支出を示す棒グラフ
- 予算の節約状況を示すダッシュボード
- カレンダー上で支出額に応じて色を表示
