# お金

`codo-core/src/money.rs` の `Money(i32)` の仕様．GUI の表示と入力欄はこれに従う．

## 演算

- `+`，`-`，`+=`，`-=` は overflow したら panic する
- `checked_add`，`checked_sub`，`checked_neg` は overflow したら `MoneyError::Overflow` を返す
- `Sum` を `Money` と `&Money` の両方に実装する

overflow したときに黙って誤った額にしない．i32 の上限は約21億円で，家計簿の年間合計には十分．

## 符号の判定

- `is_positive` と `is_negative` を持つ
- どちらも 0 を含まない (std の `i32::is_positive`，`i32::is_negative` と同じ)

## 表示

`Display` は `¥` と3桁区切りで表示する．負の値は符号を通貨記号より前に置く．

根拠: Unicode CLDR の ja ロケールの通貨書式は `¤#,##0.00` で，負の書式を別に持たないため先頭に `-` を付けた `-¤#,##0.00` になる．JPY の小数桁は 0 なので `-¥1,234` となる．
ただし記号は CLDR に従わない．CLDR の ja は JPY の記号を U+FFE5 とするが，この仕様は U+00A5 を使う．

- <https://github.com/unicode-org/cldr-json/blob/main/cldr-json/cldr-numbers-full/main/ja/numbers.json>
- <https://unicode.org/reports/tr35/tr35-numbers.html#Number_Format_Patterns>

| 値                  | 表示              |
| ------------------- | ----------------- |
| `Money(1234)`       | `¥1,234`          |
| `Money(0)`          | `¥0`              |
| `Money(-500)`       | `-¥500`           |
| `Money(1000000)`    | `¥1,000,000`      |
| `Money(i32::MIN)`   | `-¥2,147,483,648` |

出力は次の正規表現に全体一致する．`¥` は U+00A5．

```regex
^(?:¥0|-?¥[1-9][0-9]{0,2}(?:,[0-9]{3})*)$
```

- 0 は符号なしの `¥0` のみ．`-¥0` は出さない
- `+` は出さない
- 4桁以上は必ず3桁で区切る
- 前後に空白を付けない
- 出力は入力の文法に必ず一致する．したがって任意の `m` で `m.to_string().parse() == Ok(m)` が成り立つ

## 入力

`FromStr` の文法．前後の空白を除いたあと，次の順に並ぶ．

- 符号: `+` か `-` が0個か1個
- 通貨記号: `¥` (U+00A5) が0個か1個．符号より後に置く
- 数字列: 区切りなし，または先頭グループに `,` と3桁の組を繰り返したもの
  - 区切りなしなら先頭の 0 を許す
  - 区切りありなら先頭グループは1から3桁で，0 で始まらない

正規表現で書くと次のとおり．trim 前の入力全体に一致させる．全角数字を除くため `\d` ではなく `[0-9]` と書く．

```regex
^[ \t\n\x0C\r]*[+-]?¥?(?:[0-9]+|[1-9][0-9]{0,2}(?:,[0-9]{3})+)[ \t\n\x0C\r]*$
```

- 前後の空白は `trim_ascii` が除く5文字．垂直タブ (U+000B) と全角スペースは含まない
- 正規表現に一致し，かつ値が `[-2147483648, 2147483647]` に収まるときのみ受理する

| 入力                                                   | 結果                               |
| ------------------------------------------------------ | ---------------------------------- |
| `1234`，`1,234`，`¥1,234`，`  1,234  `                 | `Money(1234)`                      |
| `-500`，`-¥500`                                        | `Money(-500)`                      |
| `+5`，`007`，`-0`                                      | `Money(5)`，`Money(7)`，`Money(0)` |
| `--5`，`-+5`，`¥-500`，`¥+5`                           | `Parse` (符号は先頭に1つだけ)      |
| `0,123`，`12,34`，`1234,567`，`,123`，`123,`，`1,,234` | `Parse` (3桁区切りの誤り)          |
| 空，`¥`，`-`，`1 234`，`- 500`，`1234.0`，`abc`        | `Parse`                            |
| `2147483648`，`2,147,483,648`，`99999999999999999999`  | `Overflow`                         |

- 文法に合わないなら `Parse(元の入力)`．trim する前の入力をそのまま入れる
- 文法に合うが i32 の範囲外なら，桁数によらず `Overflow`．i64 に収まらない桁数でも `Parse` にしない
- 符号を1つに限るのは，`--5` のような打ち間違いを黙って `+5` にしないため
- `0,123` を拒否するのは，`10,123` の打ち間違いを黙って 123 にしないため
- 受け付けるのは ASCII と `¥` (U+00A5) のみ．全角数字，全角の円記号，`円` 接尾辞などの正規化は GUI 側で扱う
